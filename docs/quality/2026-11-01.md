# Quality check against the 10 rules (2026-11-01)

Checked on Windows 11, Node.js 24.19.0, TypeScript 7.0.2, fast-check 4.10.2. The engine is an
in-memory library: no network, disk, database or clock calls.

## Rules

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | N/A | No external calls: `grep -nE "catch\|async\|await\|setTimeout\|process.env" src/*.ts` finds nothing, so there is no I/O to time out and no error to swallow. Invalid input throws (`TypeError`, `RangeError`). |
| 2 | Writes safe to retry | pass | `Replica.apply` is idempotent: duplicate inserts are skipped by id (`src/replica.ts` `#integrate`), a second delete only re-marks a tombstone. Tests: "applying the same op twice changes nothing" and the convergence properties, which deliver every op again at the end. |
| 3 | No race conditions | N/A | Synchronous single-threaded code, no `async`/`await` or shared workers. |
| 4 | Don't trust the clock | pass | Ordering uses Lamport counters (`src/id.ts` `compareIds`), never wall-clock time. |
| 5 | Read before changing | pass | No env vars or config keys. Every path in the README table (`src/id.ts`, `src/ops.ts`, `src/replica.ts`, `test/*.test.ts`) exists. |
| 6 | Never break compatibility | pass | The op shape (`InsertOp`, `DeleteOp`) is unchanged; no stored format yet. |
| 7 | One source of truth | pass | `#items` is the document; `#byKey` is an index over it, updated only in `#integrate` next to the `splice` that adds the item, so they cannot drift. Node.js 24 agrees in README, `engines` and CI; TypeScript 7 in README and `package.json`. |
| 8 | Small changes, no secrets, validate input | fixed | No secrets in the repo. Every remote op goes through `assertOp`. Defect found: a peer may send the largest safe counter, after which a local insert produced ids every peer rejects, so the replicas diverged. `insert` now throws `RangeError("Lamport counter exhausted")` instead (`src/replica.ts`), with a test. |
| 9 | Tests that can actually fail | fixed | No skipped or assertion-free tests (`grep -nE "skip\|todo" test/*.ts` finds nothing). 16 hand mutations below: 10 of 14 original mutants were killed before; two survivors got tests, two are equivalent. |
| 10 | Re-verify | pass | `npm run lint` (strict `tsc --noEmit`): clean. `npm test`: `tests 18`, `pass 18`, `fail 0`. `npm audit`: `found 0 vulnerabilities`. `audit_repo.py crdt-collab-engine`: `OK`. |
